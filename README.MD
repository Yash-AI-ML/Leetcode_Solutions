## 🧠 Problem-Solving Approach

For each problem, I try to follow this process:

```text
Understand the Problem
        ↓
Think of a Brute Force Approach
        ↓
Analyze Time & Space Complexity
        ↓
Find an Optimized Approach
        ↓
Implement the Solution
        ↓
Test Edge Cases
        ↓
Review & Improve
```

The goal is not just to solve problems, but to understand **why the solution works** and how it can be optimized.
